# Assets

Place a `demo.gif` here showing the three gestures in action and it will be
picked up by the main README's banner.

Suggested recording: run `python -m handwave`, perform a pinch (volume), a fist
(play/pause) and three fingers (next track), and screen-record the webcam
window. Tools like [`peek`](https://github.com/phw/peek) (Linux),
[Kap](https://getkap.co/) (macOS) or ScreenToGif (Windows) export GIFs directly.
